# Six independently seeded directions

Six independent 160-character alphanumeric seeds were generated using Python's
cryptographic `secrets` module from a shell script before design work. The seeds
remain outside the repository and are never rendered in a design.

1. **Contact sheet:** Dense uppercase runs, doubled letterforms, and a recurring
   divisible spacing number suggested a disciplined photographic grid. Black,
   white, vermilion, oversized grotesk typography, 48px spatial rhythm.
2. **After hours:** An opening numeric cluster, paired vertical digits, scattered
   zeros, and broadcast-like letter pairs suggested late-night transmission.
   Near-black, phosphor yellow-green, cinematic widescreen photographs, small
   monospaced labels, luminous lightweight type.
3. **Field notes:** Clusters of rounded characters, doubled digits, and long
   irregular lowercase passages suggested an annotated notebook. Paper, rust,
   ink blue, expressive serif, offset prints and conversational captions.
4. **Blue frequency:** A three-digit palindrome and repeated circular forms
   suggested reflection and graphic repetition. Cobalt, lemon, white, monumental
   stacked type, split panels, bold circular and linear graphic geometry.
5. **Still life:** Dispersed numbers and balanced alternating cases suggested
   pauses and intervals. Gallery white, deep olive, restrained serif display,
   asymmetrical whitespace, uncropped portrait studies.
6. **Soft signal:** Paired zeros, twin angular letterforms, and recurring clipped
   consonants suggested sequencers and sampler labels. Purple, apricot, acid
   yellow, geometric sans, modular panels and tactile controls.

The original portfolio supplied photographs and factual project names only.
Each direction has its own composition and responsive styles. Introductory copy
is proposed editorial copy, not additional biographical claims. Photo downloads
are web derivatives; provenance is recorded in asset-sources.json.
